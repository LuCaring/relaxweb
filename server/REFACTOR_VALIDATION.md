## 红测修复验收

后续在 `codex/refactor-chat-server` 分支先提交重构，再按照 `diagnosing-bugs` 的
复现、验证假设、最小修复、回归流程处理红测。没有回退已发布的经济数值、入座规则或安全随机源。

### 根因与修复

- 庄园目录：`9e4e950` 新增 3 套普通皮肤、单价由 20000 改为 5000、矿镐耐久由
  20/35/55 改为 15/20/25，相关测试未同步。目录契约仍明确检查价格与 ID；
  行为测试按目录生成全量购买、余额边界、扣款总额及资产检查，保留事务回滚和重放断言。
  素材测试现在检查全部 11 套皮肤，而非只检查旧的 8 套。衣橱浏览器测试同步覆盖全量皮肤，
  并将默认 Python 命令改为 `python3`，仍允许通过 `PYTHON` 覆盖。
- 评级重入：观战功能引入后，进行中的牌局不允许重新入座。改为验证拒绝响应，且钱包、
  托管、流水和统计不被重复改变；没有开放中途买入来迁就旧断言。
- 麻将随机夹具：固定手牌后仍残留随机花牌，导致基础番数越过 8 分门槛；杠后补牌还可能
  连续摸到花牌，使牌墙减少不止一张。固定手牌时显式设置花牌，抢杠基础分测试关闭花牌；
  明杠/暗杠分别覆盖普通补牌和连续补花，精确断言牌墙消耗与花牌归属。
- 手机麻将布局：320px 下玩家卡片高度 58px，顶部只预留 52px，与顶部牌架重叠 6px。
  将预留高度改为 64px，保留所有不重叠断言，失败时附带元素矩形，更新样式缓存版本。
  复查 320/390/844/1024/1366/1440/1920 七档布局及截图。
- UI 旧结构：段位测试排除资产卡片；大厅测试按桌面层查找带玩家标识的气泡，检查刷新后
  不重复生成；加入正在进行的房间时验证取消不发包、确认发出 `spectate: true`，
  同时保留等待房间普通加入检查。
