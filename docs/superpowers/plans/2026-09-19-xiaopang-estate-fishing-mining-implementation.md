# 休闲庄园钓鱼、矿场与视觉升级实施计划

依据：`docs/superpowers/specs/2026-09-19-xiaopang-estate-fishing-mining-visual-design.md`

## 1. 扩展目录与数据库

- 在 `estate/catalog.py` 增加工具、鱼饵、鱼、矿物和矿层的服务端权威目录。
- 在 `estate/schema.py` 增加工具、钓鱼会话和矿场记录表，迁移保持幂等。
- 扩展物品信息与公开目录。
- 先写目录、迁移和旧存档兼容测试。

## 2. 工具与商店领域服务

- 实现购买、升级和修理鱼竿/矿镐。
- 扩展通用购买以支持鱼饵。
- 快照加入工具和有效玩法会话。
- 覆盖金币、流水、耐久、等级限制、容量与请求幂等。

## 3. 钓鱼领域与协议

- 实现确定性鱼类选择和挣扎曲线。
- 开始时原子扣除鱼饵与鱼竿耐久。
- 服务端重演输入轨迹并结算成功、断线、逃脱和超时。
- 接入 WebSocket，覆盖双连接、重试、断线恢复和伪造拒绝。

## 4. 矿场领域与协议

- 实现确定性隐藏矿壁、矿层和敲击次数。
- 开始时扣除矿镐耐久，每格由服务端揭示。
- 实现额外敲击、提前结束、自动结束和一次性入库。
- 接入 WebSocket并覆盖并发和幂等测试。

## 5. 前端玩法

- 新增 `fishing.js` 和 `mining.js`，分别负责玩法画面、输入和结果。
- 地图开放湖边与矿洞交互区域。
- 商店增加工具、鱼饵、升级与修理；仓库展示并出售鱼和矿物。
- 桌面使用键盘/鼠标，手机使用触摸按钮和大矿格。

## 6. 全局像素视觉升级

- 新增 `art.js` 统一调色板和像素绘制原语。
- 重绘地面、道路、建筑、湖泊、矿洞、树木、作物阶段和四向角色。
- 增加波纹、鱼影、火把、灰尘、落叶与结果粒子，并支持减少动画。
- 统一 HUD、商店、仓库、玩法面板和结果卡片。

## 7. 回归与浏览器验收

- 运行所有庄园领域、协议、静态前端和既有游戏测试。
- 在真实本地 WebSocket 下完成购买工具、钓鱼、挖矿、出售的闭环。
- 验收桌面和 320/390/430 像素手机布局、移动、碰撞、弹层与恢复。
- PR 前保留本地分支，等待用户确认实际 HTML 体验。
