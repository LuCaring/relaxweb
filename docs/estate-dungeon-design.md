# 庄园地下城肉鸽游戏策划草案

日期：2026-09-22

状态：玩法草案，尚未实现；具体数值、内容规模与收益需要验证

本次修订：装备刷取加入底材、随机词缀、材料打造与独特装备；保留单人自动战斗、六部位、四种品质名称和五次通关扫荡。

战斗规则补充：增加法强与法术穿透；组合增益统一为装备联动、局内肉鸽选择、环境天气三类，局内选择设置容量上限，并提供完整增益 / Debuff 总览。

核心理念：**自动操作，但玩家负责构筑。**

## 1. 产品定位与设计边界

地下城是休闲庄园中的单人刷宝玩法。玩家搭配装备进入地下城，在自动战斗之间选择路线和局内 Buff，利用装备、增益和环境之间的联动击败怪物，获取金币、装备与珍藏。

核心成长来自可选择、可替换、可继续打造的装备。玩家寻找合适底材、有效词缀组合和机制装备，通过掉落材料完善构筑，再挑战能产出更好底材与词缀的关卡。

### 1.1 已确定的需求

- 玩家本人是唯一的己方战斗单位，不加入可招募角色、职业养成或小队系统。
- 战斗自动执行，玩家负责战前装备搭配及战间构筑选择。
- 装备部位为武器、头盔、胸甲、腰带、鞋子、饰品，每个部位同时装备一件。
- 装备品质为普通、优秀、稀有、史诗。
- 主要属性为生命值、攻击力、法强、防御力、暴击率、暴击伤害、攻击速度、法术穿透。
- 玩家通过地下城获取装备，能够装备、更换、对比、出售。
- 不同装备可以联动产生额外 Buff；按本次刷装方向，将随机词缀和基础打造前置到首版，完整套装及复杂打造后续扩展。
- 最终伤害由攻击力、攻击倍率、增伤乘区、防御力、等级压制、抗性等共同决定。
- 引入天气与环境 Buff / Debuff，怪物攻击和技能能够改变环境。
- 组合增益只有装备联动、局内肉鸽选择、环境天气三种来源；局内肉鸽选择有数量上限。
- 玩家在局内可以随时查看自身全部增益与 Debuff，包括来源、具体效果、持续时间和生效条件。
- 同一关卡累计通关 5 次后，可以自动通关。

### 1.2 本草案采用的建议

以下是为串联玩法提出的暂定设计，并非已经确定的上线规则：

- 使用自动攻击时间轴，无需玩家走位、选目标或点击技能。
- 战前装备在一次探索内固定；掉落装备结算后用于下一次探索。
- 首版采用固定底材、有限随机词缀池、基础材料打造和少量独特装备。
- 普通、优秀、稀有作为可打造装备，史诗作为固定机制模板的独特装备，不构成必然更强的线性升级。
- 装备联动优先使用可替换的标签组合，避免固定两件指定名称成为唯一答案。
- 使用局内临时货币购买 Buff，避免与长期金币积累产生冲突。
- 等级压制通过底材阶位对应的装备等级与怪物等级计算；物品等级仅决定可生成词缀范围，不增加独立人物等级。
- 自动通关采用有耗时的扫荡队列，沿用现有经济“不设每日收益硬上限”的方向。
- 局内肉鸽增益暂定最多持有 6 项；满额后通过替换继续调整构筑，不继续累加数量。

## 2. 体验目标与核心循环

### 2.1 玩家应当获得的体验

1. 一件新装备能改变下一次探索的搭配，而不仅是提高战力数字。
2. 同一套装备可以通过不同局内 Buff 形成不同打法。
3. 天气、怪物技能和地表变化会影响构筑选择，且原因能够看懂。
4. 失败可以归因于生存、输出、抗性适配或联动不足，并有明确调整方向。
5. 熟悉关卡可以扫荡，主动探索的吸引力来自新关卡、新难度和新组合。
6. 普通底材、只有少量优质词缀的优秀装备、未填满词缀的稀有装备都有留下继续打造的价值。
7. 没有直接掉落升级装备时，打造材料与回收资源仍能形成可见的进展。

### 2.2 循环

查看构筑缺口 → 选择底材 / 词缀 / 材料目标 → 查看关卡天气与掉落倾向 → 搭配六件装备 → 自动战斗与战间选择 → 结算金币、装备、打造材料、珍藏 → 筛选成品与半成品 → 打造、换装或出售 / 分解 → 挑战更高难度。

首版建议一局 8～12 个节点，完整探索目标时长约 8～12 分钟。普通战目标为 20～40 秒，精英与首领战适当延长；节点数量和时长均为待试玩验证的目标。

### 2.3 永久成长与局内成长

| 内容 | 探索结束后的处理 |
| --- | --- |
| 已拥有及本局已结算的装备 | 永久保留 |
| 金币、打造材料、珍藏、关卡进度、扫荡资格 | 永久保留 |
| 本局 Buff、临时属性、探索货币 | 清除 |
| 当前生命、护盾、异常状态、房间地表 | 清除，下局重新初始化 |
| 构筑方案 | 可保存，引用玩家实际拥有的装备 |

## 3. 单人自动战斗

### 3.1 操作分工

| 阶段 | 玩家操作 | 系统自动执行 |
| --- | --- | --- |
| 出发前 | 换装、对比属性、查看联动、选关卡 | 汇总属性与风险提示 |
| 战斗中 | 观察、查看日志、调整播放速度 | 选目标、攻击、触发效果、怪物施法、环境结算 |
| 战斗之间 | Buff 三选一、选路线、购物、事件选择、撤离 | 保存选择、生成下一节点 |
| 探索结束 | 对比装备、打造、更换、锁定、出售或分解 | 发奖、记录通关次数、更新解锁进度 |

战斗中的攻击、治疗、护盾和装备效果全部自动执行，不设置依赖即时点击的闪避、格挡或终结技。

### 3.2 自动行动规则

- 武器决定自动基础攻击的表现、倍率、伤害类型和单体 / 群体形式；物理武器使用攻击力，法术武器使用法强。
- 物理攻击与自动施法共用攻击速度、暴击率和暴击伤害，不另设施法速度、法力值或手动技能栏。
- 玩家优先攻击存活的前排目标；同优先级按固定站位选择，目标死亡后自动切换。
- 装备可以明确改变目标规则，例如“优先攻击生命最低的敌人”，首版可不开放。
- 攻击间隔由攻击速度决定；首击在一个完整攻击间隔后发生，换目标不重置已经积累的进度。
- 攻速改变时保留当前攻击进度比例，不凭空补发攻击。
- 怪物根据公开的攻击间隔和技能冷却行动；危险技能提前显示读条及环境影响。
- 多个事件同时发生时，按明确且稳定的优先级处理；致死后该单位尚未执行的行动取消。
- 一轮事件顺序建议为：到期环境变化 → 周期效果 → 玩家行动 → 怪物按站位行动；每个事件及其连锁结算完毕后检查死亡与胜负。
- 双方在同一连锁内同时死亡时按探索失败处理，不计有效通关。
- 加速播放只压缩表现时间，不改变战斗时序、触发次数或收益规则。

### 3.3 生命与失败

房间之间保留当前生命，清除临时护盾和战斗异常；永久装备联动与本局 Buff 继续生效。营地和事件提供恢复，形成持续探索的风险选择。

玩家生命归零时，本次探索结束。保留此前已完成节点的奖励，当前未完成节点和首领通关奖励不发放；已拥有的装备不掉落、不损坏。节点之间可主动撤离，采用同样的已完成节点结算规则。

单场战斗设置最大模拟时长，暂定 180 秒。超时按该节点失败处理，避免无限治疗或无法互相击破导致卡局。

## 4. 装备与打造系统

本节是适配庄园的自拟规则。参考《流放之路 2》的刷取与打造思路，但不复刻其全部词缀、货币、装备限制或当前赛季数值。材料名称、词缀容量和等级规则以下文为准。

### 4.1 装备由哪些层次组成

```text
装备实例 = 部位与底材 + 底材阶位 + 物品等级 + 品质
         + 固有属性 / 固有标签
         + 随机前缀与后缀（普通、优秀、稀有）
         或独特模板效果（史诗）
```

底材是可以反复掉落的装备类型，例如快攻短刃、重击战锤、绝缘短靴。它决定基本数值倾向、武器攻击方式、允许出现的词缀池，以及可选的固有标签。同一种底材可能掉落为普通、优秀或稀有；史诗绑定指定底材和独特模板。

物品等级、词缀档位与品质分别显示，不能统称为“装备等级”。首版不再加入独立的百分比品质、打孔、符文槽或宝石连接层，控制理解负担。

### 4.2 六个部位与底材差异

| 部位 | 底材差异示例 | 常见词缀方向 |
| --- | --- | --- |
| 武器 | 短刃高攻速低基础攻击，战锤低攻速高倍率，导雷杖以法强驱动雷属性法术 | 本武器攻击力或法强、攻速、暴击、法术穿透 |
| 头盔 | 猎手头盔偏输出，守卫头盔偏生命 | 生命、法强、暴击率、抗性 |
| 胸甲 | 厚重胸甲高防御，荆棘胸甲带反击主题标签 | 本装备防御、生命、抗性 |
| 腰带 | 守卫腰带偏生存，蓄能腰带偏攻击节奏 | 生命、防御、法强 |
| 鞋子 | 绝缘鞋带环境适配标签，轻步鞋偏攻速 | 攻速、防御、抗性 |
| 饰品 | 连击坠饰、导电指环等承担构筑补足 | 攻击、法强、法术穿透、暴击、抗性 |

饰品仍只占一个槽位，不因指环、坠饰的名称增加部位。底材的标签与固有属性不占前后缀位置，也不会被基础打造洗掉。

### 4.3 保留四个品质名称，改变成长含义

| 品质 | 随机词缀规则 | 主要价值 |
| --- | --- | --- |
| 普通 | 无随机词缀，仅有底材数值与固有属性 | 合适底材的打造起点，不能默认当垃圾 |
| 优秀 | 1～2 条，最多 1 前缀 + 1 后缀 | 少量好词缀的半成品，可保留词缀继续升为稀有 |
| 稀有 | 直接掉落通常为 3～6 条，最多 3 前缀 + 3 后缀 | 主力装备与高数值成品，空词缀位保留打造空间 |
| 史诗 | 固定模板的属性与特殊效果，部分数值在模板区间内随机 | 改变玩法的独特装备，有优势也有代价 |

优秀升为稀有时只新增一条词缀，因此可能产生仅有 2 条词缀的稀有半成品；它仍可继续增缀至容量上限。稀有可以是最终毕业装备，史诗不保证属性更高，也不能通过普通 → 优秀 → 稀有的打造路线继续升出。

“普通 / 优秀 / 稀有对应打造容器，史诗对应独特模板”是本项目对四种品质的适配。史诗不是《流放之路 2》的官方品质名称。

### 4.4 八项基础属性与汇总规则

玩家仅有统一的初始基底，不存在角色差异、职业被动、人物加点或战斗经验升级。首次开放地下城给予一套可挑战入门难度的普通装备，以及一次基础打造教学所需材料。

| 属性 | 定义与显示方式 |
| --- | --- |
| 生命值 | 最大生命与当前生命分开显示 |
| 攻击力 | 物理攻击的基础伤害属性 |
| 法强 | 法术攻击的基础伤害属性；与攻击力分开计算，不默认叠加 |
| 防御力 | 降低物理伤害；不再同时降低法术伤害 |
| 暴击率 | 物理与法术直接命中共用，结算范围 0%～100% |
| 暴击伤害 | 显示暴击总倍率，例如 150% 表示 1.5 倍；加 20 个百分点后为 170% |
| 攻击速度 | 每秒自动基础攻击次数；也控制法术武器的自动施法频率 |
| 法术穿透 | 以百分点表示，只为自身法术伤害忽略目标正抗性；例如 15 点忽略 15 个百分点抗性 |

武器底材提供基础攻击力或法强、基础攻速和伤害类型；空手使用统一的物理攻击基底。抗性与环境效果在详情显示，不增加独立的施法速度、法术暴击或元素穿透属性。

为减少局部与全局计算的理解负担，首版装备随机词缀只提供固定数值：生命、攻击、法强、防御，或攻速百分比、暴击百分点、抗性百分点和法术穿透点数。不再同时提供局部攻击百分比、全局攻击百分比与条件增伤三套词缀。

```text
基础面板属性 = 统一基底 + 所有装备的对应固定数值之和
当前生命上限 / 攻击力 / 法强 / 防御力 = 基础面板属性 ×（1 + 适用状态修正之和）
攻击速度 = 武器底材基础攻速 ×（1 + 装备攻速之和 + 状态攻速修正之和）
暴击率 / 暴击伤害 / 抗性 = 对应基底 + 装备加值之和 + 状态加值之和
法术穿透 = max(0, 装备法术穿透之和 + 状态法术穿透之和)
```

同一加值只结算一次。攻击速度暂限于 0.25～4.00 次 / 秒，其他属性下限与暴击上限统一校验。状态修正遵守第 5 节的来源与叠加规则；常驻装备数值属于基础面板，不额外伪装成一套可收集 Buff。

法术穿透既不降低物理防御，也不修改目标面板抗性；它只改变本次自身法术伤害结算，不为环境伤害或其他单位提供收益。详细顺序见第 6 节。

### 4.5 三种等级的职责

| 概念 | 决定什么 | 不决定什么 |
| --- | --- | --- |
| 底材阶位 | 固定基础数值，以及用于压制计算的装备等级 | 不保证词缀好坏 |
| 物品等级 | 本实例可生成的词缀档位范围，由掉落区域与怪物来源决定 | 不直接增加攻击、防御或等级压制 |
| 词缀档位 | 一条词缀的数值区间与稀缺程度 | 不增加其他词缀数量 |

初版词缀采用 T3、T2、T1 三档，**本项目约定 T1 最强**；这是项目显示规则，不表示照用参考游戏的档位编号。物品等级只解锁高档词缀资格，并不保证一定出现高档词缀。

例如，同为“绝缘短靴·基础阶”的两件装备，物品等级不同可以允许不同雷抗词缀，但基础防御和参与压制的装备等级相同。打造不改变底材阶位或物品等级；想追求更高上限，需要重新刷取对应底材。

构筑等级仍使用六个部位的装备等级算术平均值，空部位按 1 级计算，保留实际平均值参与压制。品质、词缀数量和物品等级均不直接提高构筑等级。更换时预览压制变化，避免高物品等级但无有效词缀的装备凭隐藏加成胜出。

底材阶位只设置少量台阶并跨多个难度保留价值；等级压制必须温和，不能让高阶散件取代所有低阶机制组合。

### 4.6 随机词缀池

前缀与后缀各有独立容量，不能将空后缀位用于新增前缀。同组词缀同一装备只能出现一次，例如不同档位的最大生命词缀属于同组；底材固有属性不占该互斥组。

| 类别 | 前缀示例 | 后缀示例 |
| --- | --- | --- |
| 武器 | 固定攻击力、固定法强（由物理 / 法术底材限制） | 攻速、暴击率、暴击伤害、法术穿透 |
| 防具 | 最大生命、固定防御、限定部位的固定法强 | 火抗、雷抗、限定部位的攻速或暴击率 |
| 饰品 | 固定攻击力、固定法强、最大生命 | 暴击率、暴击伤害、法术穿透、单项抗性 |

每条词缀配置允许部位、底材标签、前后缀类型、互斥组、最低物品等级、档位区间与抽取权重。首版只开放约 18 个词缀组，减少无用组合与阅读负担。法术武器不生成仅提高物理攻击的词缀，物理武器不生成法强或法术穿透词缀；通用饰品允许跨方向搭配。

3 前缀 + 3 后缀是容量上限，不要求每个部位必须填满。简化后的合法词缀组不足时，掉落条数上限同步降低，打造在没有合法新词缀时停止；不为凑满六条而添加无效属性或重复同组词缀。

生成时先筛出合法词缀组，按组权重选择，再从该组合法档位中按档位权重选择，最后在数值区间内取值；逐条生成并更新容量与互斥条件。某组高等级档位更多，不应因此隐式增加该组被选中的概率。

词缀条数不等于有效词缀数。稀有装备拥有“高生命 + 雷抗 + 攻速”且还留有空位，可能比六条不匹配词缀更值得打造。

### 4.7 装备联动与史诗机制

保留“不同装备直接联动产生额外 Buff”，但由少量指定名字配对改为装备标签条件。同类底材、不同品质与不同词缀实例可以互相替换。

| 标签组合示例 | 联动 Buff | 获取与替代路径 |
| --- | --- | --- |
| 荆棘 + 守卫 | 每承受 3 次直接攻击，按防御力反击一次 | 荆棘胸甲搭配任意带守卫标签的其他部位 |
| 猎手 + 连击 | 每第 3 次普通攻击增加暴击率，之后重新计数 | 猎手头盔搭配连击饰品，不要求特定品质 |
| 导雷 + 绝缘 | 雷法术命中潮湿目标时追加一次按法强缩放的伤害，并降低自身带电地表伤害 | 导雷武器搭配绝缘鞋；追加伤害不继续触发联动 |

联动必须由至少两个不同部位共同满足，同一件装备不能独自激活一个配对。相同规则全身只生效一次。首版联动标签来自底材或史诗模板，随机词缀负责完善数值，避免同时追求标签和词缀导致成型过难。

独特装备的特殊效果也并入“装备联动”，需要另一部位的适配标签才能启动；单件常驻属性仍计入基础面板，不额外形成第四类组合增益。

史诗示例“暴雨之心”：装备自身提供暴雨标签，与另一部位的导雷标签联动后，每第 5 次基础攻击 / 自动施法触发泼水，内部冷却 8 秒；联动代价是降低自身雷抗。增益与代价都显示在总览并绑定该联动。它让雷雨构筑在干燥环境中启动，也需要其他装备补足生命和抗性。

史诗效果由明确模板规定，基础打造材料不增删其词缀。首版不设置全身史诗奖励，不要求集齐史诗才能进入常规高难度。完整 2 / 4 / 6 件套装留作低优先级扩展，不预设套装必定优于混搭。

### 4.8 打造材料与基本操作

打造在庄园铁匠铺进行。材料永久保留、按种类堆叠，与本局探索货币和账号金币分开。以下名称和操作是本游戏的简化方案。

| 材料 | 可用目标 | 操作与风险 |
| --- | --- | --- |
| 启灵石 | 普通装备 | 变为优秀，随机新增 1 条合法词缀；底材不变 |
| 增缀石 | 只有 1 条词缀的优秀装备 | 在另一类空位新增 1 条合法词缀，不改已有词缀 |
| 升格石 | 优秀装备 | 变为稀有，并按稀有容量规则新增 1 条随机合法词缀；保留原有词缀 |
| 拓印石 | 有合法空位的稀有装备 | 随机新增 1 条合法词缀；满词缀或无合法结果时不可使用 |
| 定向精华 | 优秀装备 | 变为稀有，新增一条由精华与部位明确指定的词缀；保留原有词缀，具体档位和数值在合法范围内随机 |

升格石与定向精华是优秀升稀有的两条可选路线，不可连续在同一件已升级装备上重复升格。精华选定的是词缀组，不保证 T1 或满数值；已有同组词缀、部位不适配或无可用档位时不能使用，也不扣材料。

所有材料都遵守前后缀容量、互斥组和物品等级限制。不提供从稀有升到史诗的材料；高级材料也不能越过底材实例的词缀上限。

首版打造保留已有词缀，通过消耗空位产生取舍，不提供免费重抽或无限撤销。不满意的结果仍可装备、出售或分解。材料掉落必须支持玩家在成长阶段实际使用，不能全部稀缺到只能长期囤积。

后续才考虑“随机移除一条并新增一条”的重铸、控制前后缀范围的催化材料、双装备重组与不可逆异化。引入时分别明确目标限制、损失风险和失败结果，首版不开放整件摧毁型打造。

### 4.9 从掉落到成品的示例

以下为本游戏的示例数值，不是参考游戏的原始词缀：

1. 玩家刷到普通“绝缘短靴”，底材阶位合适，物品等级允许出现目标雷抗档位，因此留下。
2. 使用启灵石，获得最大生命前缀；这是当前构筑需要的属性。
3. 使用增缀石，获得全局攻速后缀。此时优秀装备已有 1 前缀、1 后缀。
4. 使用雷抗定向精华，升为稀有并追加雷抗后缀；保留原有生命与攻速，现在为 1 前缀、2 后缀。
5. 剩余 2 前缀、1 后缀位，可以先穿上，也可以继续投入拓印石；每次新增结果不保证符合预期。
6. 配合导雷武器激活联动，进入渗水关卡。将来刷到更高档生命、更多有效词缀或更适合的底材时，再决定更换。

如果第二步获得的词缀不适合，就可以停止投入，保留为备用或回收；如果直接掉落三条合适词缀的稀有装备，也可以跳过前几步。成品掉落和半成品打造都是有效成长路线。

### 4.10 装备管理、筛选与回收

- 装备背包独立展示，按部位、底材、品质、物品等级、词缀、空位与联动标签筛选。
- 装备详情显示固有属性、每条前后缀的档位与数值区间、剩余空位、可使用材料。
- 首版掉落即显示完整属性，不添加逐件消耗道具鉴定的操作。
- 支持“当前构筑可用”“打造底材”“备用方案”“待回收”等玩家标记；规则过滤只折叠或高亮，不自动销毁装备。
- 对比同部位装备时，同时显示八项主要属性、抗性、物理 / 法术攻击方式、联动与构筑等级变化；不以单一战力判定价值。
- 每件装备拥有独立实例，打造保留实例身份并记录变更；保存方案引用具体实例。
- 出售换金币，分解换基础打造碎片，二者互斥。首版所有可回收装备只产基础碎片，按固定兑换表兑换启灵石或增缀石；更高阶材料与定向精华主要来自对应战斗掉落。
- 分解收益由底材阶位和获得来源对应的回收档决定，不因投入材料、添加词缀或提高品质而增加，杜绝“打造后分解”自循环返还材料。
- 出售价由底材阶位与当前品质固定配置，不按词缀好坏动态定价；不开放金币购买打造材料、高阶装备或玩家交易。
- 已装备、锁定以及当前探索快照使用的装备禁止出售、分解和打造。保存方案引用的装备默认排除批量回收，打造前提示该方案也会使用变更后的实例。
- 批量出售或分解先显示清单与总收益；打造预览消耗、保持不变的内容、候选词缀及其概率，不暗示必然提升。
- 装备仓位独立于现有庄园物品仓库；打造材料进入独立堆叠材料栏，不占装备格。
- 背包满时掉落进入待领取区，不丢弃、不自动出售；处理完待领取装备前不能开始下一局或新扫荡。

## 5. 三种组合增益与局内肉鸽构筑

### 5.1 增益来源边界

组合增益严格只有以下三种来源，不额外加入天赋、料理、宠物、庄园建筑战斗加成或独立祝福系统。

| 来源 | 如何获得 | 容量与生命周期 |
| --- | --- | --- |
| 装备联动 | 出战装备的标签组合满足条件 | 由六部位配装决定，不占肉鸽槽；同一联动只生效一次 |
| 局内肉鸽选择 | 战后、商店和事件中的统一三选一 / 替换 | 暂定最多 6 项，占同一组槽位，本局结束清除 |
| 环境天气 | 当前天气和房间地表施加 | 同时最多 1 种天气、1 种地表；随环境变化生效或移除，不占肉鸽槽 |

装备词缀提供基础属性，武器定义基础攻击方式；条件增伤、额外触发与临时状态由以上三类系统产生。独特装备提供联动标签或改变其对应联动，不另设单件独立 Buff 系统。

商店、随机事件与营地是获取或调整渠道，不是第四种增益来源。商店与事件提供的构筑效果均占用肉鸽槽；营地可以直接恢复生命，但不额外挂常驻增益。

怪物技能可直接造成伤害、施加 Debuff 或改变环境。怪物施加的负面状态不是玩家可选的组合增益来源，但必须完整出现在 Debuff 总览并显示施加者。环境若由怪物或装备改变，其持续效果统一归入“环境天气”，同时记录最初的改变者，避免重复计入两个来源。

### 5.2 肉鸽选择、上限与替换

- 普通战后提供三选一，精英战提高选项价值；玩家可以跳过。不同强度选项均只占 1 槽。
- 本局最多持有 6 项肉鸽增益，显示为“已选 4 / 6”；暂不提供额外扩容道具。
- 未满时选择一项填入空槽；满额后显示“替换已有一项”或“放弃本次奖励”，不自动覆盖。
- 所有选择、商店购买、事件奖励和首领前调整共用上限。满额时购买必须在确认替换后才扣探索货币。
- 同名增益不能重复持有，不做局内升级、叠层和额外的同系集齐奖励，简化管理。
- 一项增益产生的临时子效果不额外占槽，但必须归属于该项，不能脱离母项永久保留。其代价性 Debuff 不可单独丢弃。
- 替换只在战间执行；移除旧项及其衍生状态、清空旧项触发进度，再启用新项。已结算生命损失不返还；移除生命上限增益后当前生命不超过新上限，新增上限不自动补血。
- 不设置“每次装入立刻发资源或恢复生命”的可反复收益，防止利用替换刷取奖励。
- 前几个选项适度提高与当前武器和装备联动兼容的权重，每局提供少量重抽；已持有同名项不进入候选池。
- 探索货币仅本局购买选择或重抽使用，结束清除，不能兑换金币。局内选择结束后全部清除，下局重新构筑。

### 5.3 首批构筑方向

| 方向 | 装备基础 | 局内选择示例 | 环境关系 |
| --- | --- | --- | --- |
| 物理连击 | 攻击、攻速、暴击 | 每第 3 次基础攻击追加一次物理伤害 | 天气改变攻速或生存时需要调整 |
| 防御反击 | 防御、生命、荆棘与守卫标签 | 提高反击伤害或增加生命上限 | 防御应对物理攻击，法术环境仍需抗性 |
| 法术爆发 | 法强、法术穿透、暴击 | 提高法强，或法术命中后获得短暂增伤 | 高抗性目标使法术穿透更有价值 |
| 雷雨传导 | 雷属性法术武器、法强、绝缘标签 | 对潮湿目标增加法术伤害 | 怪物制造潮湿可被利用，也增加自身受雷伤风险 |

首版先验证其中 3 个方向。装备联动奠定打法，6 项局内选择决定本局侧重，天气与地表提供机会和风险，不再叠加另一套流派等级系统。

### 5.4 统一叠加与触发规则

- 每条效果有稳定的规则 ID，来自不同渠道的同名状态不叠加数值，保留效果较强的一份；强度相同取结束更晚的一份。各来源分别计时，强效果结束后较弱但仍有效的来源可恢复生效。
- 不同名称但修改同一属性的效果相加，再应用该属性上限；伤害提高、易伤和减伤合并进入第 6 节的统一伤害修正，不另开乘区。
- 同一规则不能因来源标签不同重复生效。环境带电水域包含潮湿时，只计算一次潮湿减抗。
- 首版状态不做多层堆叠；重复施加只按规则刷新持续时间或替换强度。已有来源与被覆盖效果可在总览详情展开。
- 基础攻击命中或直接受击事件可以触发一次追加攻击或反击，追加攻击、反击与持续伤害不继续触发其他追加攻击或反击；需要频率限制的效果显示冷却时间。
- 效果未满足条件时显示“待触发”，不计入当前面板或显示为已获得收益；触发后实时更新。

## 6. 简化伤害结算

本节为本游戏自拟规则。保留攻击 / 法强、暴击、增伤、防御 / 抗性、等级压制与法术穿透，合并重复乘区。常量与上限用于初轮验证，不代表最终平衡。

### 6.1 两条伤害路径

```text
物理基础伤害 = 攻击力 × 攻击倍率
法术基础伤害 = 法强 × 法术倍率

最终伤害 = 基础伤害 × 暴击倍率 × 统一伤害修正 × 等级修正 × 对应防护系数

物理防护系数 = 100 /（100 + max(0, 目标防御力)）
法术防护系数 = 1 - 本次有效抗性
统一伤害修正 = max(0.20, 1 + 适用增伤之和 + 目标易伤之和 - 适用减伤之和)
等级修正 = clamp(1 + 0.02 ×（攻击方等级 - 防守方等级）, 0.70, 1.30)
```

物理伤害只经过防御，法术伤害只经过对应抗性，不双重减伤。火、雷作为法术的元素标签，读取火抗、雷抗；首版不再额外叠加一层通用魔抗。武器和伤害说明直接标明“物理 / 攻击力”或“火、雷法术 / 法强”。

防御反击是唯一首版属性缩放特例：基础伤害改为“防御力 × 反击倍率”，随后按物理路径结算，不叠加攻击力或法强。

物理与法术直接攻击共用暴击率和暴击倍率；未暴击倍率为 1。玩家等级使用构筑等级，怪物使用配置等级。`clamp` 表示截断至范围内，防御不再重复计入等级差。

装备固定攻击、法强已汇入面板；联动、肉鸽选择与环境的条件增伤进入统一伤害修正一次。首版取消独立易伤与减伤乘区、固定附加伤害和百分比防御穿透，避免一条效果多次放大。

### 6.2 法术穿透顺序

```text
目标当前抗性 = clamp(基础抗性 + 装备与状态抗性增益 - 抗性降低, -0.50, 0.75)
法术穿透比例 = max(0, 法术穿透点数) / 100
本次有效抗性 = 目标当前抗性 - min(法术穿透比例, max(0, 目标当前抗性))
```

先结算目标的装备、天气、地表和 Debuff，再应用本次攻击的法术穿透。法术穿透最多把正抗性忽略到 0，不继续制造负抗性；若环境或 Debuff 已让抗性为负，保留该负值，穿透不再进一步降低。

例如目标雷抗 30%，受到潮湿降低 20 个百分点后为 10%；玩家有 15 点法术穿透，该次法术按 0% 雷抗结算，目标面板仍是 10%。若目标已为 -10% 雷抗，该次有效抗性仍为 -10%。

法术穿透不影响物理伤害、反击或环境周期伤害。不增加额外元素穿透、百分比穿透或护甲穿透属性。

### 6.3 数值例子

物理例子：攻击力 100、倍率 100%、暴击倍率 150%、统一增伤 20%、目标防御 100、双方同级：

```text
物理伤害 = 100 × 1.5 × 1.2 × 1 × (100 / 200) = 90
```

法术例子：法强 100、倍率 100%、未暴击、统一增伤 20%、目标雷抗 30%、法术穿透 15 点、双方同级，无其他状态：

```text
有效抗性 = 30% - 15% = 15%
法术伤害 = 100 × 1 × 1.2 × 1 × (1 - 0.15) = 102
```

其他条件相同但没有法术穿透时，法术伤害为 84。最终单次伤害向下取整，最低为 0；中间计算保留精度。

### 6.4 特殊伤害与护盾

- 玩家与怪物直接攻击使用同一套规则；怪物没有法术穿透时按 0 处理。
- 攻速只改变自动基础攻击 / 施法次数，不重复乘入单次伤害，也不改变怪物技能冷却。
- 首版持续伤害不暴击、不叠层、不触发追加攻击。效果若为法术持续伤害，施加时记录来源法强与法术穿透；每次跳伤读取目标当前抗性，并只应用一次穿透。
- 环境周期伤害使用关卡固定基础值与对应元素抗性，适用的环境减伤进入统一伤害修正；不读取玩家攻击、法强、法术穿透、暴击、增伤或等级，防御力也不减少火 / 雷环境伤害。
- 技能先结算直击，再改变地表；后续地表伤害归环境，不触发反击或吸血。
- 所有减伤结算后先扣护盾、再扣生命，护盾吸收不重复计算减伤。
- 首版不加入真实伤害、伤害类型转换或攻击力与法强双重缩放。

## 7. 天气与动态环境

### 7.1 两层结构

| 层级 | 作用范围 | 持续方式 | 变化来源 |
| --- | --- | --- | --- |
| 天气 / 区域气候 | 整段探索的基础条件 | 出发前可见，首版一局固定 | 关卡配置 |
| 房间地表 | 当前战斗中的公共场地 | 按持续时间衰减，离开房间重置 | 天气初始化、怪物技能、装备联动或肉鸽选择 |

地下场景可使用“渗水”“干热”“地下雷暴”等区域气候表达天气，不要求露天地图。首版场地整体共用一种地表，不要求玩家走位；双方默认都受影响，抗性或免疫例外必须显示。

状态图标同时标注来源、剩余时间、作用对象和实际效果。天气变化、地表变化以及异常状态不能只靠背景颜色表达。

天气和地表统一属于“环境天气”来源，不再单独增加湿度、温度、环境能量或反应层数。首版同一时刻只有一种天气与一种地表；地表改变后旧地表状态立即移除，新状态进入增益 / Debuff 总览。

### 7.2 首版天气与地表

天气先验证干燥与渗水两种。干燥房间从普通地表开始；渗水房间从潮湿地表开始。天气在战斗中不反复覆盖地表，让怪物和装备造成的环境变化有持续意义。

| 地表 | 效果草案 | 主要机会与风险 |
| --- | --- | --- |
| 普通 | 无环境修正 | 基准环境 |
| 潮湿 | 双方获得潮湿状态，雷抗降低 20 个百分点 | 雷系更强，玩家也更容易受雷伤 |
| 燃烧 | 按固定周期对双方造成火属性环境伤害 | 需要生命、火抗或明确的环境减伤，物理防御不生效 |
| 带电水域 | 保留潮湿效果，额外周期性造成雷属性环境伤害 | 雷系联动更强，需要绝缘类应对 |

周期、基础伤害和持续时间均由关卡难度配置；原型可先使用每 2 秒一次环境伤害、特殊地表持续 8 秒。

### 7.3 地表转换规则

首轮采用小而明确的转换表，避免无提示地叠加多种地表伤害：

| 当前地表 | 收到的环境事件 | 结果 |
| --- | --- | --- |
| 普通 | 点燃 | 燃烧 |
| 普通 | 泼水 | 潮湿 |
| 普通 | 通电 | 保持普通，仅结算技能自身伤害 |
| 潮湿 | 点燃 | 变为普通；本次点燃用于蒸干，不直接留下燃烧 |
| 潮湿 | 通电 | 带电水域 |
| 燃烧 | 泼水 | 潮湿，移除后续燃烧周期伤害 |
| 燃烧 | 通电 | 保持燃烧 |
| 带电水域 | 点燃 | 变为普通，移除潮湿与带电周期伤害 |
| 带电水域 | 泼水 / 通电 | 保持带电，刷新持续时间，不叠加周期频率 |

对同类普通地表重复施加对应事件只刷新持续时间。未列出的事件保持原地表。燃烧与潮湿到期变为普通，带电水域到期变为普通；若需要带电到期后保留潮湿，可在后续增加独立计时，首版不采用。

单个技能的顺序固定为：先按当前环境结算直击伤害 → 再改变地表 → 后续事件使用新环境。同一时间的多个环境改变沿用战斗事件顺序，后发生的效果基于前一个结果转换。

首版只有标注“改变地表”的怪物技能、装备联动或肉鸽选择会触发转换。普通火法术不会自动点燃，普通雷法术不会自动通电，防止高攻速无成本控制整个环境。

### 7.4 怪物改变环境的例子

- 渗水软泥：读条后向场地泼水，使普通或燃烧地表变为潮湿。
- 灰烬甲虫：喷火造成直接伤害，随后触发点燃；潮湿场地会先被蒸干。
- 雷晶守卫：蓄力攻击后触发通电，潮湿场地转为带电水域。
- 首领“酒窖看守”：交替泼水、通电，让玩家通过绝缘、防御或爆发构筑应对可预期的阶段变化。

怪物没有默认环境免疫。某只怪物若具有火抗或雷抗，必须在关卡预览与战斗详情中显示。玩家可以利用怪物产生的环境反过来加强自己的构筑。

### 7.5 可应对性

入场前显示初始天气、主要怪物抗性和可能发生的环境改变。途中提供能缓解当前风险的 Buff、营地或可选路线；天气不应在玩家锁定装备后无提示地完全封死其攻击类型。

同一关卡应存在不止一种可行搭配，例如绝缘装备、防御生命构筑，或在环境恶化前结束战斗的爆发构筑。

## 8. 地下城、奖励与扫荡

### 8.1 关卡、怪物与掉落目标

一个地下城由多个房间与最终首领组成，同一地下城具有独立难度档位。地图混合普通战、精英战、材料事件、商店、营地和首领；路线预览同时显示危险与奖励方向。

刷取目标包括合适底材、优秀 / 稀有半成品、可直接使用的成品、打造材料和史诗机制装备。高难度优先提高可获得的底材阶位、物品等级与有效词缀机会，不仅增加低价值装备数量。

| 来源 | 主要奖励倾向 | 玩家选择 |
| --- | --- | --- |
| 普通怪群 | 金币、普通底材、基础打造材料 | 稳定积累底材和低阶打造机会 |
| 精英怪 | 更高优秀 / 稀有权重，部分掉落排除最低词缀档位 | 承担更高风险寻找优质半成品 |
| 精华封印事件 | 可预览类别的定向精华，附带更强怪物 | 针对缺失属性选择挑战 |
| 最终首领 | 至少 1 件稀有装备、打造材料包，以及独立的史诗与珍藏抽取 | 获得基本回报，同时追求机制装备 |
| 特定区域 | 指定部位、底材或材料类别权重提高 | 针对构筑缺口选择刷取地点 |

首领保底稀有是本游戏建议规则，不表示参考游戏所有首领都采用同一保底。史诗和珍藏独立抽取，不挤占稀有装备保底；失败只保留此前已完成节点的奖励。

例如酒窖提高绝缘鞋类底材与雷抗精华的权重，熔炉区域提高重甲底材与防御类材料权重。定向刷取提高来源概率，不保证固定词缀组合，也不允许绕过物品等级。

“精英词缀”和“装备词缀”分开：怪物的雷暴、厚甲等词缀增加风险，其奖励修正必须在入场前可见。首版只配置少量固定精英变体，不引入无限随机叠加的怪物词缀系统。

### 8.2 掉落生成与经济接入

#### 8.2.1 一件装备的生成顺序

1. 根据关卡和怪物来源确定奖励次数、可用部位与底材池，处理明确的首领保底。
2. 为装备确定底材阶位与物品等级；两者可以相关，但必须分别保存。
3. 从该来源的普通 / 优秀 / 稀有权重中确定品质，再确定词缀数量；史诗使用单独抽取与模板池。
4. 普通装备不生成随机词缀；优秀和稀有按第 4.6 节规则生成合法前后缀。
5. 来源若提供“优质掉落”规则，在该次生成中排除指定的低档词缀；它不增加物品等级，也不是第五种品质。
6. 固定结果并发放装备实例，不因重连、查看或重复领取重新抽取。

来源奖励表必须预先校验词缀池有足够合法组合，不能通过重复同组词缀、越级生成或突破前后缀容量凑数。优质掉落门槛只在该次生成中生效；后续使用普通材料打造时仍按本实例合法池抽取，界面需明确。

掉落数量、品质权重、词缀档位权重和材料种类是四个独立参数。提高史诗概率不自动提高词缀数值；增加掉落次数也不自动提高物品等级。首版不开放装备上的掉宝率属性，先避免战斗配装被强制换成刷宝配装。

#### 8.2.2 长期收益与回收

- 复用现有账号金币与流水，不创建第二套永久货币余额。
- 打造材料是不可交易的消耗物，不作为金币替代币，不设置材料兑换金币入口。
- 普通底材与少词缀装备也可能有价值；过滤规则不能默认按颜色批量回收。
- 完整通关的基础材料包支持后续打造，减少没有装备升级时的空转；史诗不作为基本战力门槛。
- 珍藏接入庄园收藏，首版不出售，不直接提供无限叠加战斗属性。
- 出售与分解需要取舍：前者支持庄园金币需求，后者积累基础打造材料；已消耗材料不退回。
- 分别测算金币净收益、材料获取速度、每次打造成本、装备实际升级概率与达到基础可用构筑的时间。
- 金币收益需要包含“材料打造后出售”的完整路径，确保不形成优势明显的纯金币生产方式。
- 对照 [现有庄园经济基线](estate-economy.md) 评审，首版不增加入场费、金币洗练或无限数值强化。

### 8.3 通关 5 次解锁自动通关

“自动战斗”与“自动通关”是两个层次：前者仍需玩家选择路线与 Buff；后者直接执行已掌握关卡的扫荡结算。

- 计数单位是“地下城 ID + 难度”，不是单场小怪战。
- 玩家完成探索选择并击败最终首领记为一次有效通关，战斗本身始终自动执行。
- 累计 5 次即可解锁，不要求连续成功；失败不清空已有次数。
- 解锁永久保存，换装不会撤销已获得的扫荡资格。
- 扫荡不增加用于解锁其他难度的通关次数，不发现隐藏路线，不自动解锁新内容。
- 同一账号同时只能有一场地下城探索或一个扫荡任务，避免并发制造额外收益。
- 扫荡持续时间由关卡固定配置，离线继续计时；加速播放不缩短扫荡时间。
- 一次扫荡对应一次标准通关奖励抽取，包含正常金币、首领稀有装备保底、基础材料包，以及常规史诗与珍藏抽取；使用同难度标准奖励的底材、物品等级和词缀规则。
- 额外精英、精华封印与隐藏事件等可选节点奖励由主动探索获得，不计入标准扫荡包；基础升格、拓印材料和低概率定向精华仍可从标准材料池获得，不能强制只手动刷取全部打造资源。
- 扫荡完成后领取结果，再开启下一次；首版不做无限自动续扫或批量预约。
- 若扫荡完成时装备背包已满，奖励进入待领取区，不丢失。

扫荡时间需结合单位现实时间的收益评估，不能按最慢通关时间惩罚玩家。若后续开放探索离线自动选项，也需要与扫荡共享产出约束。

### 8.4 解锁后继续探索的动力

更高难度的底材与物品等级、不同关卡的材料与底材倾向、精英优质词缀机会、新天气搭配、隐藏珍藏和构筑记录承担长期目标。主动探索提供选择掉落方向与承担额外风险的机会，扫荡提供标准资源积累。不要通过反复取消扫荡资格或把常规史诗装备排除出扫荡来强制重复操作。

后续可增加带词缀的地下城挑战凭证，组合“敌方攻速提高”“持续渗水”等风险与明确的奖励改善。五次通关资格只覆盖对应基础难度，不自动继承任意凭证奖励；强化版本的解锁、消耗与扫荡另行设计，首版不开放。

## 9. 界面与反馈

### 9.1 装备界面

显示六个装备槽位、八项主要属性、抗性详情、构筑等级、已激活联动与待补齐联动。装备详情分层展示底材、物品等级、固有标签、前缀、后缀及空位；支持查看词缀档位和取值范围。对比同时展示基础属性、当前面板与联动增减，标明当前武器使用攻击力还是法强。

### 9.2 关卡准备界面

显示关卡难度、怪物等级、抗性、天气、可能出现的环境变化、掉落倾向、通关进度，例如“3 / 5，通关 5 次解锁扫荡”。可从当前页面直接调整装备。

### 9.3 战斗界面

优先展示玩家与怪物生命、护盾、行动进度、怪物危险读条、当前天气和地表，以及“肉鸽选择 4 / 6”和“全部增益 / Debuff”固定入口。战斗中、战间和选择界面都能打开总览；桌面点击或手机点按即可查看详情，不依赖悬停。

战斗日志保留最近的关键事件，例如“软泥泼水 → 潮湿 → 雷抗降低”“守卫通电 → 带电水域”“绝缘联动减少环境雷伤”。击杀时清楚区分武器、反击、持续伤害和环境贡献。

总览完整列出自身状态，支持“全部 / 增益 / Debuff”筛选，默认同时展示正负效果，不只保留最近几个图标：

| 分组 | 展示内容 |
| --- | --- |
| 装备联动 | 激活该规则的装备、效果和代价，区分已生效、待触发与冷却中 |
| 局内肉鸽 | 6 个槽位、每项选择的完整效果和其衍生状态，显示已用数量 |
| 环境天气 | 当前天气与地表实际施加的增益 / Debuff、转换来源与剩余时间 |
| 当前 Debuff 汇总 | 汇总上述三类的代价以及怪物直接施加的负面状态；它是负面效果视图，不是第四种组合增益系统 |

每条记录至少显示名称、具体数值、影响属性或伤害类型、规则来源、施加者、剩余时间 / 永久条件、触发条件与当前是否生效。例如“潮湿：雷抗 -20 个百分点；环境天气 → 渗水软泥泼水；剩余 5 秒”。对玩家有利但同时带代价的规则同时展示两面，不把雷抗降低藏在联动说明末尾。

同一状态在来源分组与 Debuff 汇总中引用同一条记录，不重复计数。存在覆盖时显示实际生效的一份，展开可查看仍在计时的被覆盖来源。未触发的条件加成单列“待触发”，不计入已生效增益数值。

面板同时展示基础值、当前值与来源拆解；临时状态、持续伤害、护盾剩余量和负面效果不得因图标数量多而消失，列表可滚动。状态到期、地表转换、Buff 替换和重连后同步更新，不显示已失效的状态。查看面板不改变自动战斗时间轴；战间保持可查且不自动推进选择。

### 9.4 结算界面

显示金币、装备、打造材料、珍藏、有效通关进度、输出来源和主要受伤来源。失败时给出可解释信息，例如“本局受到的伤害中，带电地表占 42%”，帮助玩家调整装备，而非只提示战力不足。

### 9.5 打造与回收界面

选择装备后展示可用材料、前后缀空位、合法候选词缀、概率与消耗。打造结果对比前后变化，并保留最近操作记录；不提供重新进入界面重抽结果的机会。

支持一键跳转“这类底材 / 材料在哪里掉落”。保留底材与备用装备的标记优先于批量回收筛选，史诗、已锁定和已装备物品默认保护。

## 10. 首版范围与扩展顺序

### 10.1 最小可玩版本

- 一个玩家单位，无角色库、职业或人物技能树。
- 八项主要属性，物理与法术两条伤害路径，共用攻速与暴击；首版即支持法强和法术穿透词缀。
- 六个装备部位、四个品质，约 12 种底材类型，每种最多 2 个基础数值阶位。
- 约 18 个随机词缀组，每组最多 3 档；少量固定模板史诗，首轮暂定 3 件。
- 3 组装备标签联动，约 18 个候选肉鸽增益，每局最多持有 6 项，先形成 3 种可行构筑。
- 组合增益仅来自装备联动、局内肉鸽选择、环境天气；不做同系集齐奖励与增益叠层。
- 启灵、增缀、升格、拓印四种基础打造操作，以及少量定向精华类别。
- 1 个地下城、3 个难度档位，约 6 种普通 / 精英怪物、1 个首领。
- 干燥与渗水两种天气，普通、潮湿、燃烧、带电水域四种地表状态。
- 成品和底材掉落、装备、更换、对比、筛选、锁定、出售、分解、待领取与存档。
- 金币与打造材料奖励、少量珍藏、完整结算与五次通关扫荡。
- 局内完整增益 / Debuff 总览、满槽替换、来源与持续时间显示，以及可解释的伤害和失败反馈。

### 10.2 后续扩展

1. 增加底材、词缀、史诗机制与定向材料来源，验证更多跨流派组合。
2. 增加重铸和有限的打造控制材料，再考虑装备重组、不可逆异化；分别说明风险。
3. 评估是否需要镶嵌与正式套装：镶嵌只补基础属性，套装归装备联动，继续遵守三类组合增益来源。
4. 增加霜冻、浓雾等天气及地表，逐项补充环境转换规则。
5. 增加带词缀的挑战凭证、隐藏首领、构筑收藏与战斗回放。

不将多人组队、PVP、装备交易或人物职业加入当前范围。若未来增加召唤效果，优先表现为装备产生的自动伤害事件，不引入可独立养成的角色。

## 11. 持久化与规则一致性要求

本节仅记录玩法依赖的数据要求，具体接口、表结构和模块边界另行设计。

- 装备实例、打造材料、穿戴方案、珍藏、通关次数、扫荡状态及金币结算以服务端为准。
- 装备实例保存底材类型与阶位、物品等级、品质、词缀组与档位及数值、史诗模板、回收档和版本，不用名称或客户端面板推导。
- 出发时保存装备与规则版本快照，探索内不换装、不出售、不分解或打造快照使用的装备。
- 保存本局路线、随机结果、选择、当前生命、Buff 和已完成节点；重连恢复，不重新抽取奖励。
- 保存肉鸽槽位与每项选择的规则 ID；获取、购买和替换在服务端统一校验最多 6 项，同名不能重复，断线或并发请求不能超出上限。
- 替换确认、扣探索货币、移除旧状态及启用新项在一次事务中完成；取消或校验失败不扣费。
- 状态记录包含规则来源、施加者、增益 / Debuff 标记、数值、条件、到期时间和母项引用；面板与战斗结算共用同一状态快照，重连保留未到期效果与冷却。
- 玩家离线时可完成当前自动战斗，遇到需要选择的节点后等待；不擅自替玩家选择 Buff 或路线。
- 发奖、出售、分解、材料兑换、打造、有效通关计数与扫荡领取均需幂等；请求重试不能重复获得金币、材料或装备。
- 打造校验、扣材料、生成结果、修改装备与记录操作在一次事务内完成。重复请求返回同一结果；同装备并发请求不能覆盖词缀或突破容量。
- 分解和出售互斥地消耗同一装备实例；材料兑换检查数量与固定配方，不能通过负数或重复请求增发。
- 模拟结果不依赖浏览器帧率、播放速度和是否打开战斗页面。
- 环境和 Buff 触发有明确来源、顺序、同名覆盖与到期规则，首版不叠层，连锁不能无限执行。
- 新规则不改变已经完成的奖励记录；正在进行的探索使用出发时固定的版本。

## 12. 验证标准与待定参数

### 12.1 玩法验证

- 同一入门关卡至少存在 3 种可通关构筑，并且不共享同一件必备史诗装备。
- 同品质装备之间存在可解释的取舍，至少有一个低品质联动组合优于不适配的高品质组合。
- 普通底材与优秀半成品有明确保留理由，优质稀有装备可以胜过不适配的史诗装备。
- 玩家可以完整执行“普通底材 → 优秀 → 定向精华升稀有 → 追加词缀”，过程保留已有词缀并遵守前后缀容量。
- 无合法词缀、已有同组词缀、满词缀或目标品质不符时，打造不扣材料；低物品等级无法生成越级词缀。
- 精英优质掉落不会突破词缀等级上限；后续普通材料追加词缀不会错误继承原掉落的档位保证。
- 连续未获得装备升级时仍能积累基础打造机会；成型时间不以单件低概率史诗为前提。
- 玩家可以通过对比界面理解换装为什么改变输出、生存和联动。
- 同一装备组合更换局内 Buff 后，战斗表现有明显差异。
- 物理攻击不使用法强或法术穿透，法术不额外计算防御；暴击与攻速在两种武器上口径一致。
- 验证正抗性、零抗性、负抗性以及潮湿状态下的穿透结算：穿透不能把正抗性降到负值，环境伤害不继承玩家穿透。
- 三类来源外不存在隐藏组合增益；单件独特装备不绕过装备联动要求，事件和商店不绕过肉鸽容量。
- 第 7 项肉鸽奖励只能替换或放弃；满槽购买、并发选择、断线重试都不额外占槽或错误扣费。
- 替换移除旧项及其衍生状态、代价和触发进度，不返还已损失生命，不保留失去来源的增益。
- 增益 / Debuff 总览能展示全部当前效果、怪物施加者、条件、剩余时间及覆盖关系；未触发项不误报为已生效。
- 天气、地表、同名状态和面板修正不重复计算；房间切换、到期和重连后显示与结算一致。
- 天气既能成为风险也能成为机会；至少一种怪物制造的环境可被玩家利用。
- 环境免疫、连击与反击不产生无限循环；攻速上限附近也能稳定结算。
- 通关第五次准确解锁对应难度扫荡；其他难度进度不受影响。
- 失败、撤离、掉线、背包满、重复领取都不会丢失已确认奖励或重复发奖。
- 扫荡与同难度标准奖励使用相同装备生成规则，不能越级获得底材、独占挑战奖励或高档词缀。
- 重试、并发打造及重复出售 / 分解不会重复扣料、重抽词缀或制造资源。
- 已解锁扫荡的玩家仍有明确的新关卡、装备或组合目标。

### 12.2 数值验证

重点验证攻击与法强的成长、法术穿透在不同抗性下的收益、防御收益、攻速触发频率、暴击收益、等级压制与环境伤害占比。所有方向同时测试普通怪、精英、首领，以及干燥和渗水环境，不能只在单一木桩目标上比较。

验证输出同时记录通关率、平均剩余生命、战斗耗时、Buff 选择分布、底材与词缀使用率，以及单位现实时间金币与材料收益。刷装模拟需要分别统计直接掉落升级率、半成品保留率、基础构筑成型时长、指定两条 / 三条有效词缀的获取成本及材料消耗。

首版材料与词缀池以不交易、仅自给自足的玩家为基准评估；同时检查碎片兑换和“打造 → 出售 / 分解”的完整资源循环。先完成离线模拟，再用实际试玩检查选择是否有趣。

### 12.3 实施前需要收敛的参数

| 参数 | 当前建议 / 待验证内容 |
| --- | --- |
| 初始基底与新手装备数值 | 保证普通入门装备可通关，不要求先获得稀有掉落 |
| 底材阶位与物品等级 | 前者影响基础数值与压制，后者只限制词缀；分别验证跨度 |
| 词缀权重与档位区间 | 首轮约 18 组、最多 3 档，纳入法强与法穿，验证有效组合概率与统一属性汇总 |
| 法术穿透 | 暂用固定点数忽略正抗性，上限为当前正抗性，不单独产生负抗性 |
| 局内肉鸽容量 | 暂定 6 项，满额替换；结合 8～12 节点节奏验证成型速度与选择负担 |
| 伤害修正 | 增伤、易伤与减伤相加，统一修正最低 0.20，不额外新增乘区 |
| 打造材料与分解兑换 | 验证常用操作可负担、定向精华有价值、升级分解不产生材料循环 |
| 联动触发倍率与次数 | 与攻击速度、怪物攻击频率共同验证 |
| 品质概率与保底 | 完整通关至少一件稀有与基础材料包；史诗独立抽取，史诗累计保底尚未确定 |
| 装备容量与扩容费用 | 使用独立装备容量，具体数值待经济评审 |
| 金币与出售价格 | 对照现有庄园整体收益，不在草案写死 |
| 扫荡耗时 | 按标准奖励的单位时间收益配置，支持离线计时 |
| 环境持续时间与周期伤害 | 原型先用 8 秒持续、2 秒周期，验证可读性和生存压力 |

## 13. 参考方向与来源

- 《流放之路 2》：本次装备刷取的主要参考，借鉴底材与半成品价值、词缀筛选、材料驱动打造、独特装备改变机制，以及更高挑战提供更好掉落起点的方向。

- 《原神》圣遗物：保留装备组合产生额外收益的参考方向，具体刷取与成长已改为底材、词缀与打造，不以成套替换全部散件。
- 《土豆兄弟》：参考自动攻击与装备、属性选择驱动战斗的方向。
- 本草案以玩家单人自动战斗为基础，不引入参考作品的人物职业、天赋树、多人交易或赛季重置。
