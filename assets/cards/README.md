# Guandan joker icon

`joker-flat.png` is an original icon generated with the built-in imagegen tool.
It is an RGBA PNG with a transparent background. The game uses the same asset
in color for the big joker and with a CSS grayscale filter for the small joker.
No operating-system emoji is used for these card faces.

## Generation prompt

Use case: logo-brand. Asset type: tiny corner icon for a Guandan playing card. Create one original flat vector-style joker / court jester head icon on a genuinely transparent background with alpha, no card or enclosing frame. It must remain legible at only 24 pixels wide: a simple friendly smiling ivory face, bold dark navy contours, a three-point jester hat with red and teal panels and small golden bells, minimal geometric details, symmetrical compact silhouette. Use solid flat colors, no gradients, no shadows, no 3D, no texture, no emoji styling, no text or lettering, no watermark. Single centered icon tightly framed with just a small transparent margin. The same icon will be used in color for the big joker and rendered grayscale with CSS for the small joker. Save the generated transparent PNG for use as an actual project asset.
