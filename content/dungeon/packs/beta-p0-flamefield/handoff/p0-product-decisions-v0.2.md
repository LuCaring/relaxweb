# P0 一页产品决策表 V0.2

更新日期：2026-09-25。本表冻结下一版 2D 俯视房间战斗原型的产品边界，替代《P0一页产品决策表V0.1》草案。上位规则：《小胖地下城游戏总案V3.1》《小胖地下城战斗系统策划案V1.3》。

**冻结记录**：2026-09-25 项目负责人对话拍板四项——技术栈（网页 TypeScript + Phaser）、首条路线（4 房线性）、P0 不接局外经济、先文档后代码；其余"待确认"行按 V0.1 建议方向转正或划入 P1/P2。仍开放项见文末；未列入开放项的内容不再作为悬而未决处理。

**路线解释补充（2026-09-25）**：这里的“4 房线性”指普通→普通→精英→Boss 的**无分叉推进顺序**，不限制房间的地图坐标共线；空间分布可按种子曲折变化，约 55D 以可走路径量测。布局提案见 [G03 空间布局 V0.2](./G03四房空间布局与刷怪配置讨论稿V0.2.md)。

**竖切细则补充（2026-09-25）**：[P0 战斗竖切决策记录 V0.2](./P0战斗竖切决策记录V0.2.md)已确认连续地图短连接段、进入下一房不能退回、有效种子 50—60D、全怪物软分离且接触本身无伤、远程不后撤/不在镜头外开火、弹道不穿墙、P0 Boss 无半血新形态及统一计时口径。本表原有产品边界不变；试作体型和速度未运行验收。

## 决策表

| 决策项 | 冻结口径 | 状态 | 若改动会影响 |
|---|---|---|---|
| 原型类型 | 玩家手动移动、逐房间推进的战斗原型；不是站桩单目标，也不是单图定时生存 | **已冻结** | 所有 P0 表 |
| 视角 | 2D 俯视；参考《吸血鬼幸存者》《土豆兄弟》的空间与威胁可读性，不沿用其系统规则 | **已冻结**；镜头缩放／跟随／遮挡参数开放，留原型测试 | 地图尺寸、碰撞、动作、美术与 UI |
| 玩家操作 | 键盘（WASD／方向键）手动移动；武器自动索敌并执行攻击；首版不做手动瞄准与攻击按钮 | **已冻结** | 输入、AI、动作取消窗、难度 |
| 单局结构 | 多房间推进，部分中途房间有精英怪；完成前置房间目标后由玩家主动进入独立 Boss 房；击败 Boss 后结算 | **已冻结** | 房间拓扑、刷怪、结束条件、奖励 |
| 首条路线 | 4 房线性推进：普通房×2 → 精英房×1 → Boss 房；不分叉，空间可曲折，具体规格见 [G03 V0.2](./G03房间拓扑与遭遇刷怪表V0.2.md) | **已冻结（V0.2）** | G03 拓扑、制作预算 |
| 计时规则 | 常规地下城不设全局倒计时，也不靠时间自动触发 Boss；高难度计时玩法留未来单独评审 | **已冻结** | 关卡目标、刷怪、UI 与难度 |
| 技术栈与平台 | 网页 TypeScript + Phaser 3；PC 浏览器优先；键盘输入；手柄／触屏暂不要求 | **已冻结（V0.2）** | 工程搭建、确定性模拟、打包与发布 |
| 战斗内保留 | P0 无局内强化系统：跨房间只保留当前 HP（无自动回复）；局内强化属 P1（G05），实装后按"跨房保留、离开地图清除"执行 | **已冻结（V0.2）** | 续航、商店与存档 |
| 局外保留 | P0 不接局外经济与存档：结算只产出带唯一 battle_id 的结果记录（含事件日志），奖励生成与存档写入的接口预留到 G08／G09 | **已冻结（V0.2）** | 奖励与回档 |
| 失败代价 | P0 玩家生命首次归零即失败，本局结束、不产出奖励；局外资产不受影响（P0 本不接局外） | **已冻结（V0.2）** | 风险、刷取效率、撤离策略 |
| 撤离 | P0 不开放主动撤离；撤离玩法与收益归属留待 P1 评审 | **已冻结（V0.2）** | 单局长度、经济、存档 |
| 玩家交易 | 首个原型不做玩家间交易，避免装备价值、复制风险和经济测算同时扩张 | **已冻结** | 装备绑定、掉落和经济 |
| 首个内容切片 | 一条 4 房线性路线；一个场景主题（萤灯原野·外围营地，占位名，取自《1至60级地图与怪物概念V2.0》第一城段）；长剑基础自动近战 1 个玩家动作；普通怪 2 种＋精英 1 种＋Boss 1 种；美术可用占位资源，房间和敌人结构必须完整 | **已冻结（V0.2）** | 制作预算和验收周期 |
| 本轮不做 | 六把武器完整 60 点树、全量地图、玩家交易、完整制作经济、局内商店、共鸣／专精实装——按清单进入 P1/P2，不作为 P0 启动条件 | **已冻结** | 项目排期 |

## 现有资料的适用边界

**后续配置同步（2026-09-25）**：本表的“P0 无局内强化、无装备掉落”不排斥 [G03 V0.2](./G03房间拓扑与遭遇刷怪表V0.2.md) 已确认的精英房后保底药瓶：它接触即恢复最大生命 30%，不能携带或跨房保留。动作、遭遇与伤害的现行首测配置分别见 G02/G03/G04 V0.2；这些表的可调数值尚未通过运行验收。

- 《小胖地下城1至60级地下城地图与怪物概念交接V2.0》的六城概念只提供场景与怪群视觉方向；其等级段、刷新频率、招式数值不是生产配置。竖切主题名与怪物名取自"萤灯原野"段，均为可改占位。
- 《小胖地下城战斗系统策划案V1.1》《V1.2》中可保留的工程原则（确定性模拟、结果与表现分离、奖励唯一性）已并入 V1.3；其旧关卡结构与旧公式不再适用。
- 《小胖地下城1至80级地下城生物设计交接文档V1.0》建立在旧单目标基础上，仅作生物概念备选。
- 《长剑武器专精节点总表V0.4》是 P2 数据结构样例；P0 只使用长剑基础攻击，不接任何专精节点效果。

## 冻结条件

本表冻结口径自 V0.2 起生效。按 V0.1 既定验收条件，完全生效还需随原型补齐：①"入口房→普通／精英房→Boss 房→结算"流程图（G03 已附）；②一段含移动与自动攻击的可复测战斗记录（原型轮产出）；③失败／撤离奖励归属例（本文档"失败代价""撤离"两行即当前口径示例）。变更任一冻结行须提升版本并记录受影响的配置、UI 与测试用例。
