# G02 动作表与敌人招式表 V0.2

更新日期：2026-09-25。上位规则：《小胖地下城战斗系统策划案V1.3》、[P0 产品决策 V0.2](./P0一页产品决策表V0.2.md)、[数值决策表 V0.1](./伤害数值体系待确认决策表V0.1.md)、[G04 公式与事件 V0.2](./G04战斗公式与事件表V0.2.md)。本表取代 G02 V0.1 的动作与索敌配置。敌人名称来自地图概念稿，仅作原型占位。

**状态**：已确认规则与可调测试配置并列。长剑基础节奏、80°范围、最多 6 目标、索敌权重、玩家移速、敌方伤害档位与重招频率为已确认口径；P04—P08 的碰撞、远程、撞墙和 Boss 阶段边界见 [P0 决策记录 V0.2](./P0战斗竖切决策记录V0.2.md)。体型、具体前后摇、投射物速度等仍是**待实测占位值**。无可运行工程，尚未验收。

## 1. 通用动作与移动合同

- 角色手动移动（WASD／方向键），主武器自动攻击；基准玩家移速为每秒 **4 个玩家碰撞体直径**。若测试暂用玩家半径 16px，则直径 32px、移速 128px/s；像素换算随最终碰撞体尺寸调整，不反向改变设计速度。
- 模拟固定步长暂按 60Hz 试作，动作由前摇→命中窗→后摇组成；同一单位同时最多执行一个主行动。长剑基础挥斩期间保持 **100% 移速**，玩家移动不占主行动槽。
- 受击硬直、击退、动作打断暂不启用；取消窗与资源支付在 P0 均为“无”。这只是原型占位，不是六种武器的永久规则。
- 敌人预警区域与真实命中碰撞区域必须一致。一次主行动对同一目标的基础命中上限为 1；未来多段攻击需独立定义每目标上限。派生命中及伤害结算按 G04 V0.2。
- 敌方**命中**在玩家 0.4 秒受击窗口内只计最高一笔；窗口内后到的更强命中只补差额，DoT 不纳入该窗口。记录每笔来源，即使部分伤害被窗口抵消。
- **P04 已确认**：所有怪物与玩家、怪物彼此软分离；墙体和未开放通道仍硬阻挡。贴身接触本身不扣血，只有有效招式命中或状态跳伤才结算伤害。软分离的解算顺序和位移上限必须固定，不能推出墙体或造成同帧瞬移。

## 2. 长剑基础动作与自动朝向

| 字段 | `P_SWORD_SLASH` 长剑基础挥斩 |
|---|---|
| 触发 | 有可攻击敌人且玩家不在其他主行动中，自动开始。 |
| 首测面板与伤害 | 固定保底长剑总面板攻击威力约 **72**；动作系数 **100%**、纯物理；基础暴击率 **5%**、暴击伤害倍率 **150%**。Gain／Inc／More、暴击、防御和护盾顺序见 G04 V0.2。 |
| 周期 | **0.6 秒/次**。首测可用前摇 250ms＋命中窗 100ms＋后摇 250ms 分配；三段比例是动画/手感占位，周期是已确认基准。 |
| 形状 | 以玩家为顶点的 **80° 扇形**，半径暂按 **2.5 个玩家碰撞体直径**；不再以 90°/90px 为现行口径。 |
| 命中上限 | 每主行动最多 **6 个不同目标**，每目标最多 1 次；命中至少一敌时基础剑势最多获得 1 层，不随扇形命中人数叠加。 |
| 多目标系数 | 第 1 个目标用 100% 动作系数；第 2～6 个目标各用 **90%**，不随目标序号继续递减。命中目标的排序须稳定记录，首测按目标权重高者先、同权重按距离近者先、再按单位 ID。 |
| 移动与取消 | 全动作保持 100% 玩家移速；P0 无手动取消和消耗。 |
| 范围成长接口 | 专精可增加角度、距离或作用范围；角度构筑目标约 **110～120°**，当前长剑节点百分比仍是占位，须另轮平衡。 |

**自动选朝向**：每次准备挥斩时枚举能覆盖敌人的候选 80° 扇形，按**实际可命中的最多 6 名目标的权重之和**选最高价值方向：普通怪=1、精英=4、Boss=7。若总分相同，先选包含当前锁定目标的方向，再比较目标距离，最后以单位 ID/角度的固定顺序打破平局。命中窗开始时锁定朝向与扇形；实际命中以命中窗碰撞为准。若前摇中原目标失效，重新计算一次候选方向；已无合法目标则取消并记 `action_cancel`。算法要输出候选得分、选中方向和最终命中顺序，供种子回放。

**空间命中澄清（C01，2026-09-25 已确认）**：候选覆盖和实际命中均以扇形与敌方**受击体相交**且没有墙体遮挡为准，不要求敌人中心进入扇形。墙体遮挡须用稳定的攻击射线/碰撞规则判定；大型敌人的外沿可先于中心进入 2.5D 范围。受击体尺寸、浮点容差与边缘相切用例仍需原型配置，不改变 80°、2.5D 和最多 6 目标的既定上限。

## 3. 敌人招式首测档位

首阶参考怪物生命：普通怪 **60**、精英 **400**、Boss **1200**；生命值属 G03/G04 配置，不再沿用旧稿 Boss 300。下表伤害是**对基准防御玩家的单次有效伤害目标**，不是可直接填入引擎的 raw 值；raw 必须用 G04 防御公式倒推并实测。玩家首阶基础生命 100、基准护甲约 K/4。

精英与 Boss 招式选择器不得因“冷却就绪”而无视重招频率约束。旧稿的固定 raw 8/6/14/10/18/22 不是新数值基准。**P08 已确认 P0 不做 Boss 半血新形态**，仅用横扫与冲锋轮换，保留后续阶段事件接口。P07 已确认夜蛾俯冲/Boss 冲锋撞实体墙即停，普通怪不作为硬阻挡；预警与实际扫过区一致，对玩家每主行动最多一次有效命中。所有弹道不穿墙，遇墙销毁并记录原因。怪物体型与速度按上表试作，投射物上限须随地图尺寸统一标定。普通怪/精英/Boss 的房间总失血预算依次为约 5～8%／10～15%／25～35% 最大生命，须与动作命中率一起验收；不能把每招都按预算累计视为玩家必吃伤害。

## 4. 事件与验证

动作产生 `attack_start`、`hit`、`damage`、`action_end`、`action_cancel`；投射物额外产生 `projectile_spawn`、`projectile_hit`，撞墙销毁记 `projectile_wall_hit`，达到容量而未发射时记 `attack_suppressed`；Boss 入场/后续阶段接口可产生 `phase_change`，但 P0 不做半血形态切换。每个事件携带 `action_id`、`source_id`、`config_version`、`seed`；伤害分量、实际扣盾/扣血和暴击字段采用 G04 V0.2，不能恢复旧 G04 的 raw→先扣盾→防御链。

| 用例 | 验收预期 |
|---|---|
| 多目标自动朝向 | 摆放普通怪、精英与 Boss，使“最近目标方向”与“最高覆盖价值方向”不同；应选择后者，至多 6 目标，得分与打破平局的理由可在日志复算。 |
| 长剑群攻 | 80°/2.5 直径范围内摆放 7 名敌人，单次至多命中 6 名；目标 2～6 用 90% 动作系数；本次基础剑势仅 +1。 |
| 长剑移动 | 持续输入移动并挥斩，前摇、命中窗、后摇的玩家移速均为 4 直径/秒，不被攻击动作自动降低。 |
| 重招与受击 | 夜蛾/Boss 重招有 ≥0.7 秒预警，冷却满足 3～4 秒/4～5 秒目标；0.4 秒窗口内多笔敌方命中只取最高一笔，DoT 另算。 |
| 公式归因 | 同一固定种子下记录暴击掷点、各类型防御前后值和实际扣盾/扣血；重复播放事件序列一致。 |

仍开放：试作体型/移速的最终数值、绝对像素、动作三段配比、普通招式间隔与位移、减速和击退、投射物容量、相机可见性判定的具体帧、软分离解算参数。**Boss 半血新形态不在 P0 开放项内**。这些参数必须通过原型版本化配置与试玩确认；不得把上表占位字段当作已完成平衡。
